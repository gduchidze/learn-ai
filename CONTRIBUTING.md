# Contributing

Thanks for helping improve **learn-ai**. Fixes to numbers, new case studies and clearer explanations are all welcome.

## Quick start
1. Fork and clone the repo.
2. Open the folder as an [Obsidian](https://obsidian.md) vault, or use any Markdown editor.
3. Make your change on a branch and open a PR.

## Note style
- **One concept per note.** Split a note once it covers two ideas.
- **Start with a 🟢 Junior Explanation** callout: the idea in plain words, plus a one-sentence answer.
- **Link generously** with `[[Note Name]]` wikilinks, to prerequisites and to follow-ups.
- **Cite sources.** Use tags like `[WEB]` or `[OS]` and add links. Numbers must be verifiable.
- **Prefer diagrams.** Mermaid renders on both GitHub and Obsidian.

## Naming
- Folders: `NN-kebab-case` (e.g. `04-retrieval-and-rag`).
- Notes: Title Case with spaces (e.g. `Semantic Cache.md`). Wikilinks resolve by filename, so **don't rename notes** without updating the links that point to them.

## Commits
Use [Conventional Commits](https://www.conventionalcommits.org): `docs: add note on paged attention`, `fix: correct H100 bandwidth number`.
